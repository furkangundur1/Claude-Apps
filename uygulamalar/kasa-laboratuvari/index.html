Kasa Laboratuvarı

Solda kasa programını kullanıcı gibi deneyebilirsin. Sağda aynı programın içini görüyorsun: bilgisayarın gördüğü ham baytlar, makine kodu ve o koddan geri çevirdiğimiz okunur C kodu. Turuncu yazı, üç katmanda da aynı sırrı işaretliyor.

Dışarıdan bakış

Programı çalıştır

$ ./kasa Kasa sifresi:

Bu terminal, gerçek programın tarayıcıdaki kopyası. Programı aynı mantıkla taklit ediyor ve aynı mesajları veriyor. Asıl derlenmiş dosya Linux'ta çalışıyor ve sonuçlar orada da aynı çıktı.

İçeriden bakış

Aynı programın katmanları

Şifre 0x2004 adresinde başlıyor. Ekrana hiç yazılmayan tek yazı da bu.

objdump ile çıkarılan gerçek makine kodu (x86-64). İşlemcinin adım adım çalıştırdığı komutlar bunlar.

Makine kodunu satır satır okuyup elle geri yazdığım C kodu. Ghidra'nın decompile özelliği bu işi otomatik yapar. Değişken isimleri derlemede kaybolduğu için benim seçimim; fonksiyon isimleri ise dosyada duruyordu.

int sifre_kontrol(const char *girilen) {
    return strcmp(girilen, "kirmizi-elma-42") == 0;
}

int main(void) {
    char tampon[64];
    printf("Kasa sifresi: ");
    if (fgets(tampon, 64, stdin) == NULL)
        return 1;
    tampon[strcspn(tampon, "\n")] = '\0';   // Enter'ı sil

    if (sifre_kontrol(tampon))
        puts("Kasa acildi!");
    else
        puts("Yanlis sifre.");
    return 0;
}

1 · Ham baytlarİçinde okunabilir yazılar aradık ve ekranda hiç görünmeyen kirmizi-elma-42 yazısını bulduk.
2 · Makine koduKodu okuduk. sifre_kontrol fonksiyonu girileni tam olarak o adresteki yazıyla karşılaştırıyor.
3 · Geri çevrilmiş CProgramın mantığını okunur koda çevirdik. Artık programın ne yaptığını baştan sona biliyoruz.
