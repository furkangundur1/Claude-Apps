# Belgeler

Bu belgeler Claude Docs'ta duruyor: kullanıcı ve Claude birlikte düzenliyor, yorum bırakılabiliyor. Asıl içerik oradadır. Bir sohbette Claude Docs bağlantısıyla (`read` / `export`) okunabilir ya da belgenin kendi Dışa aktar menüsünden Markdown, Word veya PDF olarak indirilebilir.
